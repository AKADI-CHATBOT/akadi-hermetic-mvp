# D-06 - Version minima de Python y estilo - CERRADO

- Decision: D-06 = Regla universal de declaracion obligatoria.
- Regla universal: Todo componente debe declarar version minima de Python
  y estandar de estilo. Sin declaracion, no se acepta.
- No se fija una version unica global en este cierre. Cada componente
  declara la suya y queda registrada.
- Alcance: Cierre documental Fase A.
- Fuente: Decision del custodio, 2026-11-23, regla universal.
