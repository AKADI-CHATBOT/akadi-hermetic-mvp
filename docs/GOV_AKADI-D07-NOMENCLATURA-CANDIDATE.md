# D-07 - Nomenclatura N2 - CERRADO

- Decision: D-07 = Distincion obligatoria entre clase y estado.
- Regla universal: Clase N2 y Estado N2 son distintos y no se mezclan.
- Clase N2 = categoria de regla, N2 Reglas generales segun D-01 Opcion A.
- Estado N2 = estado de cumplimiento o de proceso respecto a esa clase.
- Cuando se use N2, debe indicar si es clase o estado.
- Alcance: Cierre documental Fase A.
- Fuente: Decision del custodio, 2026-11-23, regla universal.
