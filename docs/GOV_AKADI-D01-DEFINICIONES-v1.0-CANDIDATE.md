# D-01 - Definiciones - CANDIDATE

## MUDF - CERRADO CON FUENTE
- Expansion: MATRIZ UNIVERSAL DE DETECCION DE FALLOS
- Version de referencia: 4.0, Documento unico mejorado
- Definicion: Metodo para auditar cualquier objeto, sistema, proceso o idea
  y convertir fallos en decisiones ordenadas por prioridad y verificables.
- Tipos: Error, Bug, Gap, Entropia
- Prioridad: Severidad x Probabilidad x Detectabilidad (1-36)
- Evidencia: E0 a E3
- Fuente: Documento MUDF v4.0 aportado por custodio. MUDF_IMAGENES v1.0
  es aplicacion de MUDF a auditoria de imagenes WA0007, no la definicion.
